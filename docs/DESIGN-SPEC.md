# 设计规范（DESIGN-SPEC）

## 1. 分辨率与渲染

| 项 | 值 |
|---|---|
| 逻辑分辨率 | **480 × 270**（16:9） |
| 缩放 | 整数或半整数倍（CSS `image-rendering: pixelated`） |
| 主循环 | 固定步长 `1/60`，累加器最多补 6 步 |
| 地面线 | `GROUND = 232`（玩家脚底） |

## 6. 美术接入接口（P4 用）

把 `drawPlayerBig / drawGuardBig / drawShooterBig / drawEliteBig` 内部替换为画图即可，签名保持：

```js
drawPlayerBig(ctx, p, t)      // p: {x,y,w,h,face,vx,vy,atkT,parryT,dead}
drawGuardBig(ctx, e, t, dead) // e: {x,y,w,h,dir,alive}
```

角色建议规格：**24×40**，锚点脚底中心；帧：idle 2 / run 6 / dash 1 / attack 3 / hurt 1 / death 3。
背景建议规格：远/中/近 3 张 **960×540 透明 PNG**（或 480×270 二倍图），视差 0.06 / 0.13 / 0.90；瓦片 16×16。

## 7. 音频参数（`game/audio.js`）

| 项 | 值 |
|---|---|
| 总线 | `master(0.8) → Compressor(threshold -14, ratio 4) → 输出` |
| 混响 | Convolver，1.6 s 生成脉冲，wet 0.32 |
| 刀声 | 带通噪声 4.2k→700Hz（随连段上移）+ 宽频尾 + 三角波泛音 + 低频推力 |
| 命中 | 噪声 crunch + 150→52Hz 正弦 + 320→120 三角 |
| 化劲 | 520/780/1170/1560Hz 四正弦，1.4 s 衰减 |
| 死亡 | 220→40Hz 锯齿 + 低频噪声 |
| BGM | 五声音阶 D 调 Karplus-Strong 拨弦，620ms 一步，随机八度 + 低频持续 |
| 环境 | 3 s 布朗噪声 → 低通 1.4k → 0.09Hz LFO |
