# 刀客 · 陈霜 —— 第一关（原创原型）

一个可玩的单关横版动作原型：一击必杀、化劲（弹反）、冲刺、死亡即重开、化劲成功时缓。
**全部素材为程序化绘制的原创图形，未使用《Katana ZERO》任何素材。**

## 1. 立刻玩（本机已起服务）

浏览器打开 <http://127.0.0.1:8123/index.html>（服务由 `node serve.js` 提供，端口 8123）。

想看机器人自动演示：<http://127.0.0.1:8123/index.html?demo=1&frames=430>

## 2. 用手机玩（同一 WiFi）

1. 电脑上运行 `node serve.js`（已在跑）；
2. 查电脑内网 IP：`ipconfig` 里的 IPv4 地址，例如 192.168.1.20；
3. 手机浏览器打开 `http://192.168.1.20:8123/index.html`。

触屏会自动出现虚拟按键（左/右/跳/J/K/冲）。

## 3. 打成真正的 APK（需要 JDK 17 + Android SDK）

> 生成 APK 必须要有 JDK 与 Android SDK/gradle；当前这台机器没有（已验证：无 java/javac/sdkmanager/gradle，且不能联网安装）。工程文件已备好，在**有环境**的机器上执行：

```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug        # 产物: android/app/build/outputs/apk/debug/app-debug.apk
```

装到手机：`adb install -r app-debug.apk`，或把 APK 传到手机点击安装（需允许“未知来源”）。

发布版（要签名）：

```bash
keytool -genkey -v -keystore chendao.keystore -alias chendao -keyalg RSA -keysize 2048 -validity 10000
./gradlew assembleRelease      # 再 apksigner sign --ks chendao.keystore ...
```

## 4. 不想装 Android Studio 的替代路线

- **PWA / 添加到主屏**：把 `www/` 部署到任意 HTTPS 静态托管（GitHub Pages、Netlify、Vercel），Android Chrome 打开后可“添加到主屏幕”，体验接近原生。
- **Cordova**：`cordova create . && cordova platform add android && cordova build android`（同样需要 JDK+SDK）。
- **桌面版**：`npx electron .` 或 Tauri，把同一份 `www/` 包起来。

## 16. 音频系统（本轮重写，程序化合成，零素材）

文件：`audio.js`（`window.ChenDaoAudio`），`game.js` 里的 `makeSfx()` 优先委托给它。

| 层 | 实现 |
|---|---|
| 总线 | `master → DynamicsCompressor → 输出`，另有 `send → Convolver(1.6s 生成脉冲) → wet(0.32)` 混响 |
| 刀声 | 三层叠加：带通噪声扫频（4.2k→700Hz，随连段上移）+ 宽频噪声尾 + 三角波金属泛音 + 低频推力 |
| 命中 | 噪声 crunch + 150→52Hz 正弦下坠 + 320→120 三角波 |
| 化劲 | 4 个正弦分音（520/780/1170/1560Hz）1.4s 长衰减 + 高频噪声闪 |
| 死亡 | 220→40Hz 锯齿 + 低频噪声 |
| BGM | 五声音阶（宫商角徵羽，D 调）**Karplus-Strong 拨弦**，620ms 一步，随机八度与低音持续 |
| 环境 | 3s 布朗噪声循环 → 低通 1.4k → 0.09Hz LFO 起伏 = 雨声底噪 |

**浏览器要求首次交互后才能出声**：点击画面或按任意键即可解锁（代码里已挂在键盘/触摸事件上）。

## 25. 背景精致化（本轮，照原作结构改）

### 先看他们怎么做的（来自 game.droid 的结构证据）

| 证据 | 含义 |
|---|---|
| `BGND` 82 条，命名全是 `bg_*_tileset` 与 `bg_*_alpha` | 背景是**图块集**，并且有独立的 alpha 蒙版层做视差/遮罩 |
| 房间 15 层里有 `Backgrounds_1` / `bg_tiles` / `fg_tiles` | 背景 / 后景图块 / 前景图块三层分离 |
| 独立实例层 `fog` / `halogens` / `blood`（各自 depth） | 雾、灯光、血是**代码画的**，不是贴图 |
| 748 个 Draw 事件 | 大量效果走代码绘制与叠加 |

→ 结论：精致不来自一张大图，而是 **分层 + 每层各自视差 + 用雾做出空气透视 + 光照单独一层**。

### 我这轮按这个结构重写

| 层 | 内容 | 视差 |
